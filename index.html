2. Voice Conversion to a Canonical Neutral Voice

Converting any voice (Male or Female) into a standardized gender-neutral canonical timbre (~160 Hz) while preserving 100% linguistic intelligibility.

Standardizing Speaker Identity via Universal Background Transport

In addition to arbitrary speaker-to-speaker conversion, our framework enables converting any input speech directly into a standardized, gender-neutral canonical voice.

By centering representations against the source speaker's local centroids μX,k, whitening via ΣX,k-1/2, and transporting directly onto the balanced 40-speaker universal background (ck, Σshared,k), we neutralize individual speaker timbre:

zneutral(t) = ∑k wt,k [ ck + (xt - μX,k) Aneutral,k ].

4. Code & Quickstart

Easy-to-use, modular Python library and CLI tool. Installable directly with pip.

📦 Installation (Pip)
# Clone and install boosted-lwt git clone https://github.com/<your-username>/boosted-lwt.git cd boosted-lwt pip install -e .
⚡ Command Line Interface (CLI)
# Zero-shot voice conversion boosted-lwt convert \ --source input.wav \ --target target_ref.wav \ --output converted.wav \ --alpha 1.5 # Convert to canonical neutral voice boosted-lwt pure-content \ --source input.wav \ --output neutral.wav
🐍 Python API Quickstart
from boosted_lwt import VoiceConverter # 1. Initialize converter (auto-loads WavLM, HiFi-GAN, and balanced UBM) converter = VoiceConverter(device="cuda") # 2. Zero-shot Voice Conversion with Boosted LWT (alpha=1.5) converter.convert( source="source.wav", target=["target_ref1.wav", "target_ref2.wav"], alpha=1.5, output_path="converted.wav" ) # 3. Convert to Standardized Canonical Neutral Voice (~160 Hz, CER 0.00%) converter.extract_pure_content( source="source.wav", output_path="neutral_voice.wav" )
